# Optional platform dependencies for HireSnap.
#
# WHY this is a separate file from requirements.txt: the base image must stay
# runnable exactly as it is today. The platform layer (src/infra, src/workers)
# imports redis, celery and boto3 LAZILY inside the backend factories, so a
# container built from requirements.txt alone still starts, still serves
# uploads, and still passes the test suite with every feature flag off. Install
# this file only in images that actually run a worker or talk to redis/MinIO:
#
#     pip install -r requirements.txt -r requirements_platform.txt
#
# Pinned exactly, for the same reason every other dependency is pinned: a
# floating minor version turns a rebuild into an unreviewed upgrade.
#
#   celery   task queue used by src/workers/celery_app.py; 5.4.x is the last
#            line that still supports the Python 3.9 runtime of this image.
#   redis    client for the cache facade and, through celery, the broker and
#            the result backend (db 1 - operational state, never business data).
#   boto3    S3/MinIO client behind STORAGE__BACKEND=s3. Pinned together with
#            botocore indirectly; do not pin botocore separately or the pair
#            can drift apart.

celery==5.4.0
redis==5.0.8
boto3==1.35.24
